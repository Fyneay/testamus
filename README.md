# testamus
Хук для блокировки запросов с информацией о списывании.  
Изменения касаются только информации о списывании по api, на странице теста будут показаны нарушения (если проктор включил отображение списывания при решении теста).  
Но как правило их отключают.

## Описание
Перехват и блокировка запросов с api экзамуса через [Chrome DevTools Protocol (CDP)](https://chromedevtools.github.io/devtools-protocol/) при прохождении тестов.  
GET и PUT запросы перехватываются и отправляются без изменений. Если POST запрос, то проверяется тело на наличие полей с уведомлением о списывании, при наличии полей запрос блокируется со стороны клиента с событием `ErrorReasonTimedOut`.

## Установка
1. Скопировать репозиторий
>git clone https://github.com/Fyneay/testamus.git
2. Собрать сборку для образов (если ничего не правили, шаг можно пропустить)
> docker build .
3. Для компиляции приложения использовать команду go run
> CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -o main.exe .
> CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o main.exe .
4. Запустить файл, должен открыться браузер на движке Chromium (Google Chrome, Chromium и т.д.)  
> [!note]  
> Откроется вкладка с about:blank, не надо ее закрывать, нужно заменить эту конструкцию на ссылку с теста экзамуса (или любую ссылку, которая потом откроет тест)

## Памятка
### Отключение консоли приложения при запуске браузера (Windows)
Если компиляция файла происходит на Windows, рекомендуется отключить консоль, т.к. в консоли будут появляться логи  
Для отключения консоли на этапе 3 лучше написать следующую команду:
```go RUN CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -ldflags="-H=windowsgui" -o main.exe .```  
  
### Исправление ссылки на чтение запросов
Ссылка на проверку запросов настроено на `*/api/v2*`, если по каким-то причинам тест или сайт, который перенаправляет на тест работает некорректно, то рекомендуется уточнить ссылку, например: `*moon.examus.net/api/v2/*`
```go
		fetch.Enable().WithPatterns([]*fetch.RequestPattern{
			{
			 	URLPattern:   "*moon.examus.net/api/v2/*", 
				 // ...
			},
		}),
```
